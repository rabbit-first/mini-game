# Mini Game Hub

一个只使用 HTML、CSS 与原生 JavaScript 构建的迷你游戏大厅，可直接部署到 GitHub Pages，无需构建步骤或后端服务。

## 游戏内容

- 猜数字：猜测 1 到 100 之间的随机数，查看提示、次数和本局记录。
- 今晚吃什么：从 30 种常见餐饮中随机抽选，抽选过程持续 3 秒。
- AI English Coach：提供 112 个软件工程词汇、语法示例检查、场景对话和工程师表达练习。
- 每日英语任务与学习成就：完成目标可领取金币与经验，学习记录单独保存在浏览器本地。
- 成长系统：每日登录奖励、金币、经验、自动升级；成就数据字段已预留。

## 本地预览

直接在浏览器打开 `index.html` 即可游玩。Google Fonts 仅用于字体装饰；断网时会自动使用系统备用字体，游戏本身不依赖网络。

## GitHub Pages 部署

将项目文件推送到 GitHub 仓库，在仓库的 **Settings → Pages** 中选择部署分支和根目录即可。入口文件为仓库根目录的 `index.html`。

## 存档

玩家资料、每日奖励状态、游戏统计和进行中的游戏保存在浏览器 `localStorage` 中；英语学习进度使用独立的 `mini-game-hub-english-v1` 键保存。语法检查和对话目前使用内置模拟数据，不会向 AI 服务发送内容。清除浏览器站点数据会同时清除本地存档。
